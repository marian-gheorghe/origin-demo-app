# origin-demo-app

## Overview

This is a small demo application implementing a dose-calculation service. It
centers on `DoseService`, which validates a request body and computes a
patient's dose in milligrams, and `DoseFormatter`, which rounds and renders
that computed dose for display. The app has no real-world clinical use;
it exists purely as a minimal, self-contained target used to exercise
Origin's real-agent run pipeline end to end.

**PRIVATE demo target repo for the Origin platform (Phase 2).** This is the
repository a real coding agent fixes *through Origin* in the Phase 2 demo. It
is intentionally tiny: a plain-Java Gradle dose service with **two seeded
bugs**, each pinned by a failing test.

## Seeded bugs

| # | Requirement | Bug | Pinned by (failing test) |
|---|-------------|-----|--------------------------|
| 1 | "The system shall reject a null request body before dereferencing it." | `DoseService.computeDoseMg` dereferences the request body without a null check, so a null body raises `NullPointerException` instead of `ValidationException("request body must not be null")`. | `io.origindemo.dose.DoseServiceTest.rejectsNullRequestBodyBeforeDereferencingIt` |
| 2 | "The displayed dose shall be rounded to one decimal place." | `DoseFormatter.formatDisplayDose` truncates (`Math.floor`) instead of rounding half-up, so `12.36` displays as `12.3` instead of `12.4`. | `io.origindemo.dose.DoseFormatterTest.displaysTheDoseRoundedToOneDecimalPlace` |

## Red/green contract

```
./gradlew test
```

fails on a clean clone on **exactly the two tests above** (the other tests
pass). Fixing both bugs turns the suite green. That is the demo agent's job.

## Base SHA = the demo RepoRef

The HEAD commit of `main` in this seeded state is the **base SHA** that the
Origin demo run targets: it is recorded in the run's `RepoRef`
(cloneUrl, branch, baseSha), and the agent's PR is diffed against it. Do not
push fix commits to `main`; the agent works on a branch off this SHA.

## Reseeding

This repo is (re)generated by `e2e/seed-demo-app.sh` in the Origin repo.
Re-running it is a no-op while the repo exists; pass `--force` to force-push a
fresh seeded-buggy history (this rewrites `main` and produces a new base SHA).
